# Ashabesuffa Foundation — Images

Static images for the website.

## Files Required

| File | Purpose | Recommended Size | Format |
|---|---|---|---|
| `logo.svg` | Vector logo (preferred) | any | SVG |
| `logo.png` | Raster logo fallback | 200 × 200 | PNG |
| `favicon.png` | Browser tab icon | 32 × 32 | PNG |
| `favicon.ico` | Legacy favicon | 32 × 32 | ICO |
| `hero-bg.jpg` | Homepage hero background | 1920 × 1080 | JPG |
| `page-header.jpg` | Inner page headers background | 1920 × 600 | JPG |
| `about.jpg` | Homepage about image | 1000 × 800 | JPG |
| `about-2.jpg` | About page image | 1000 × 800 | JPG |
| `share-preview.jpg` | Social share (OG image) | 1200 × 630 | JPG |
| `pattern.png` | Optional background pattern | 512 × 512 | PNG |
| `placeholder.jpg` | Fallback for missing images | 800 × 600 | JPG |

## How to Replace

1. Delete the placeholder and drop your own file with the **exact same name**.
2. Keep sizes reasonable (compress with https://tinypng.com).
3. Do not rename — the HTML/CSS references these exact filenames.

## Security

- PHP execution is disabled.
- Directory listing is disabled.
- Only image MIME types are served.
